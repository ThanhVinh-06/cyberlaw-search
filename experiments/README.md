# Thực nghiệm

- `results/`: kết quả so sánh TF-IDF, embedding và phương pháp kết hợp khi đã thực hiện.
- `archive/mockup-check.js`: bản JavaScript trích từ mẫu giao diện cũ để kiểm tra cú pháp ở giai đoạn thiết kế; giữ để tham khảo, không phải mã đang chạy hoặc bộ kiểm thử.

Mỗi kết quả thực nghiệm cần ghi: ngày chạy, cấu hình, mô hình/phiên bản, tập dữ liệu, máy chạy, chỉ số và các trường hợp lỗi. Không đưa số đo giả vào báo cáo. Hiện chưa có kết quả đánh giá truy hồi.
