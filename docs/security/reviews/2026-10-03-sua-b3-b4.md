## 1. Bối cảnh & Mô tả các lỗ hổng

1. **B3 (Credential quản trị mẫu hiển thị ở route `/admin`):**
   - Trước đây tại `AdminAccessDenied.tsx` có khối *"Tài khoản Quản trị viên mẫu để kiểm tra"* hiển thị email `admin@cyberlaw.vn` và mật khẩu `admin12345`.
   - Các chuỗi này bị bundle vào file JavaScript production (`dist/assets/index-*.js`), tạo rủi ro lộ credential và thông tin mẫu gây hiểu nhầm.

2. **M5 (Thẻ hồ sơ Quản trị viên hardcode trong `AdminStatsPage.tsx`):**
   - Tại `AdminStatsPage.tsx`, thẻ hồ sơ góc phải hardcode `"Quản trị viên Hệ thống"`, `"@admin • admin@cyberlaw.vn"`, và `"Super Admin • Toàn quyền"`.
   - Đây chính là đường rò rỉ còn lại khiến `admin@cyberlaw.vn` và `Super Admin` vẫn xuất hiện trong bundle JS sau khi đã sửa B3. Đồng thời, mọi quản trị viên khi đăng nhập đều thấy tên giả thay vì tên thật của tài khoản mình.

3. **B4 (Số liệu demo vẫn hiển thị khi API `/api/admin/statistics` lỗi):**
   - State `statistics` khởi tạo bằng các hằng số demo (`thongKeTongQuanData`, `thongKeTheoThangData`...) và khi `.catch` chỉ lưu `setStatisticsError` mà không reset `statistics` về rỗng.
   - Hậu quả: Khi backend gặp lỗi 500/503 hoặc mất mạng, trang thống kê vẫn vẽ 1.280 người dùng / 3.450 hỏi đáp / 4.430 tra cứu khiến admin lầm tưởng là số liệu thật từ MySQL.
   - `RecentQuestionsCard` và `RegulationBreakdownCard` mặc định lấy dữ liệu demo `danhSachCauHoiGanDay` và `nhomQuyDinhData`.

## 2. Các thay đổi kỹ thuật đã thực hiện

### 2.1 Khắc phục B3 & M5
- **`AdminAccessDenied.tsx`**: Đã loại bỏ hoàn toàn khối credential mẫu. Khi chưa đăng nhập, trang chỉ hiển thị hướng dẫn và nút dẫn tới trang `/login`. Khi đăng nhập bằng tài khoản không có quyền admin, chỉ thông báo từ chối quyền truy cập với tên tài khoản của chính người dùng (`currentUser.ho_ten`).
- **`AdminStatsPage.tsx`**:
  - Tích hợp hook `useAuth()` để lấy `currentUser`.
  - Avatar chuyển sang hiển thị chữ cái đầu viết hoa từ họ tên của tài khoản đăng nhập hiện tại (`currentUser?.ho_ten`).
  - Tên quản trị viên: Hiển thị `{currentUser?.ho_ten || "Tài khoản Quản trị"}`.
  - Handle email: Hiển thị `{currentUser?.thu_dien_tu ? `@${currentUser.thu_dien_tu.split("@")[0]} • ${currentUser.thu_dien_tu}` : "—"}`.
  - Badge phân quyền: Hiển thị `{currentUser?.vai_tro === "admin" ? "Quản trị viên • Toàn quyền" : "Tài khoản hệ thống"}`.
  - Số bảng CSDL hiển thị chuẩn 13 bảng theo schema MySQL thực tế: `MySQL 8.0 • {overview?.so_bang ?? 13} bảng`.

### 2.2 Khắc phục B4
- **`AdminStatsPage.tsx`**:
  - Khởi tạo `const [statistics, setStatistics] = useState<AdminStatistics | null>(null);`.
  - Trong `.catch`, gọi đồng thời `setStatistics(null)` và `setStatisticsError(...)`.
  - Xóa bỏ toàn bộ import hằng số demo từ `@/lib/admin-data`.
  - Khi chưa có dữ liệu hoặc API lỗi:
    - 4 thẻ chỉ số hiển thị giá trị gạch ngang `" — "` thông qua helper `soLuong`. Dòng phụ hiển thị `"Chưa có dữ liệu"`.
    - Biểu đồ xu hướng hiển thị thông báo trạng thái rỗng `.cl-stats-empty-notice` (*"Chưa có dữ liệu truy vấn"*), không vẽ cột giả.
    - Danh sách người dùng tích cực và biểu đồ donut hiển thị thông báo trạng thái rỗng (*"Chưa có dữ liệu người dùng hoạt động"*, *"Chưa có dữ liệu trích dẫn"*).
  - Khi đang tải (`statisticsLoading = true`), giữ nguyên hiệu ứng skeleton mờ tinh chỉnh và khi chuyển bộ lọc giữ nguyên hiệu ứng sóng nước (Mazer Liquid Wave) của biểu đồ cột.
- **`RecentQuestionsCard.tsx` & `RegulationBreakdownCard.tsx`**:
  - Bỏ import dữ liệu demo `danhSachCauHoiGanDay` và `nhomQuyDinhData`.
  - Đổi giá trị mặc định của prop `items = []`.
  - Khi `items` rỗng, hiển thị khối rỗng `.cl-question-empty-wrapper` và `.cl-reg-empty`.

## 3. Bằng chứng kiểm thử & Quét bảo mật Bundle

### 3.1 Quét Bundle Production (`npm run build`)
Chạy lệnh kiểm tra chuỗi trên bundle JavaScript đã nén (`dist/assets/index-*.js`):

```bash
node -e "
const fs = require('fs');
const path = require('path');
const dir = 'frontend/dist/assets';
const file = fs.readdirSync(dir).find(f => f.startsWith('index-') && f.endsWith('.js'));
const content = fs.readFileSync(path.join(dir, file), 'utf8');
const terms = ['admin@cyberlaw.vn', 'Super Admin', 'Quản trị viên Hệ thống', 'Lê Hoàng Long', 'admin12345', '1.280', '4.430'];
terms.forEach(t => console.log(t.padEnd(28), (content.split(t).length - 1)));
"
```

- `admin@cyberlaw.vn`: **0**
- `Super Admin`: **0**
- `Quản trị viên Hệ thống`: **0**
- `Lê Hoàng Long`: **0**
- `admin12345`: **0**
- `1.280`: **0**
- `4.430`: **0**

Toàn bộ 100% các chuỗi credential mẫu và số liệu demo đã được triệt tiêu khỏi bundle production.

### 3.2 Kiểm thử Tự động E2E (Playwright)
- `frontend/e2e/admin-access-denied.spec.ts`:
  - Kiểm tra `/admin` khi chưa đăng nhập: Không chứa các chuỗi rò rỉ, hiển thị link đăng nhập.
  - Kiểm tra `/admin` khi đăng nhập quyền `user`: Hiển thị đúng tên tài khoản thật, không rò rỉ credential mẫu.
- `frontend/e2e/admin-stats.spec.ts`:
  - Test hồi quy B4: Giả lập API trả về lỗi HTTP 503, xác nhận alert hiển thị, không leak bất kỳ số demo nào (`1.280`, `3.450`, `4.430`), các ô số trả về `—`, 0 câu hỏi, 0 cột biểu đồ. Sau đó bấm *"Tải lại dữ liệu"* hồi phục thành công và vẽ lại đầy đủ dữ liệu.
